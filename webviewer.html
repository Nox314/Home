Bereit für deine erste Seite

Gib eine URL ein. Der Viewer versucht zuerst eine Vorschau mit Proxy, und wenn eine Seite nicht eingebettet werden kann, öffnet er sie automatisch im normalen Browser-Tab.

Verlauf

Wichtig: Keine reine HTML-/JavaScript-Seite kann eine fremde Website gegen deren eigene Sicherheitsrichtlinien zwangsweise in ein iframe einbetten. Deshalb versucht diese Version zuerst einen Browser-ähnlichen Proxy-Vorschau und fällt auf einen echten Tab zurück, wenn eine Seite das Einbetten verweigert. Der Verlauf bleibt nur lokal im Browser.
