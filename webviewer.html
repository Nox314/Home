Bereit für deine erste Seite

Gib eine URL ein. Wenn die Seite das Einbetten blockiert, wird sie automatisch in einem neuen Tab geöffnet.

Verlauf

Wichtig: Keine reine HTML-/JavaScript-Seite kann eine fremde Website gegen deren eigene Sicherheitsrichtlinien zwangsweise in ein iframe einbetten. Deshalb versucht diese App zuerst eine Vorschau und öffnet eine Seite automatisch in einem echten Tab, wenn das Einbetten verweigert wird. Der Verlauf bleibt nur lokal im Browser.
